# 차트뷰 토스 미니앱 출시 전 QA — 2026-09-28

대상: `https://chart-view-toss.onrender.com`, GitHub `feat/apps-in-toss-mvp`. 최초 실서비스 QA는 `0.9.2`, 후속 토스 조회형 범위 조정은 `0.9.3`이다. 브라우저 QA는 실제 Render 정적 사이트와 실제 공용 API를 사용했다. 모의 API 시험과 실데이터 시험을 구분한다.

## 판정

**웹 기능 QA: 조건부 통과. 공개 앱 등록: 보류.** 하이닉스 검색·관심종목·상세·홈·전체 히트맵, 차트 비교가 실제 배포 화면에서 동작했다. 운영자가 전달한 토스 공식 회신은 조회형 서비스를 허용하고 종목 추천·투자 권유는 어렵다고 했다. 이에 `0.9.3`은 PICK 구현을 보존하되 토스 배포본에서 선정 TOP3·추천 성과·PICK 진입과 데이터 요청을 비활성화했다. 데이터 사용·재배포 권한, Android/iOS Toss Sandbox 실기기, 콘솔 경로, 공용 API 콜드스타트가 미해결이다. 이 브라우저 결과를 토스 앱 승인이나 원거래소 시세 인증으로 확대하지 않는다.

## 속도 관측

실서비스 1회 전체 화면 측정에서 관심목록 첫 카드 240ms, 차트 761ms, 히트맵 389ms, 상세 현재가 1,644ms였다. 홈 첫 방문은 4,343ms였고 그중 정적 사이트 응답 시작까지 2,817ms였다. 1회 표본이라 P95가 아니다. 다른 3회의 저장된 관심 가격 표시는 267~283ms였으며 DOM 준비 후 84~85ms였다. 공용 API는 Render `free` 웹서비스로 확인되었고 15분 무요청 시 휴면할 수 있으므로 캐시가 없는 첫 방문의 일관된 속도를 보증할 수 없다.

## 남은 출시 차단 조건

1. 운영자가 전달한 앱인토스 회신은 문의에 명시한 무료 조회형 범위만 가능하다고 했다. 선정 TOP3/PICK은 `0.9.3` 토스 빌드에 넣지 않는다. ‘참고용’ 문구만 붙여 재노출할 근거는 없다. 실제 최종 심사 통과는 보장되지 않는다.
2. Yahoo/Naver/Finnhub/FRED/뉴스 제공처별 공개 앱 표시·캐시·파생·재배포 조건의 서면 근거가 없다. API 호출 성공은 이용허락이 아니다.
3. Android/iOS Toss Sandbox QR에서 익명 사용자키, 저장 목록 분리, 내비게이션·뒤로가기, 외부 링크, 키보드, 오프라인·복구, 화면 성능을 검증하지 못했다. 이 작업 환경에는 연결된 기기가 없다.
4. Toss 콘솔의 주요 기능 스킴, 앱 정보와 최종 `0.9.3` AIT 일치 상태를 확인하지 못했다. Render의 임의 종목 경로 rewrite도 미설정이다.
5. Render Free API 콜드스타트, 실사용자 P95, 공급자별 휴장일·발표주기와 원거래소 20종목 대사가 남았다.
