# Apps in Toss 정책 검토 요청 자료

작성일: 2026-09-21  
상태: **문의 전송 전 / 공식 답변 대기**

## 서비스 목적

Chart View는 사용자가 직접 선택한 한국·미국 주식과 공개 시장 데이터를 조회·비교하는 정보 도구입니다. 현재 미니앱은 증권 주문, 계좌 연결, 중개, 자문 계약, 자동매매 또는 사용자 자금을 다루는 기능을 제공하지 않습니다.

## 검토를 요청할 실제 기능

1. 시세와 과거 가격·기간 수익률 단순 조회
2. 사용자가 직접 선택한 최대 6개 종목의 수익률 비교
3. PER/PBR/ROE/배당수익률 등 재무지표 비교
4. 거래량·이동평균·RSI 등 기술 신호를 조합한 ‘종목 탐색’ 화면
5. 금리·물가·유동성·위험 지표의 규칙 기반 설명 문구
6. 사용자가 저장한 관심종목의 외부 뉴스 선별 노출
7. 종목 상세에서 가격·차트·재무지표·관련 뉴스 조회
8. 기기 로컬 관심종목 저장

## 정책상 특히 확인이 필요한 화면

- **종목 탐색**: 현재 ‘신호 점수’와 기술 조건을 표시함. 특정 종목 추천 또는 투자전략으로 해석되는지 확인 필요.
- **시장 지표 요약**: 투자 행동을 지시하지 않고 관측된 신호 구성을 설명하도록 문구를 변경했으나 허용 범위 확인 필요.
- **맞춤 뉴스**: 관심종목 기준으로 직접 관련/업종 관련 기사를 선별함. 외부 매체의 투자 의견 기사가 포함될 수 있음.
- **밸류에이션 비교**: 값의 높고 낮음을 종목 우열이나 추천으로 표시하지 않음.

## 데이터 제공·처리

- 시세/차트/일부 재무: Yahoo 계열 공개 데이터 엔드포인트와 기존 Chart View 데이터 파이프라인
- 한국 종목 일부 보완: Naver Finance
- 경제지표: FRED/Federal Reserve 계열 원자료를 미러·사전 캐시한 데이터, Dallas Fed PCE
- 뉴스: NAVER API HUB / Finnhub Company News
- 미니앱은 외부 데이터의 원문 기사 본문을 재게시하지 않고 제목·출처·게시시각·링크 중심으로 표시

## 매매·수익모델

- 현재 미니앱 내 주식 매매·중개 기능: 없음
- 증권 계좌 연결: 없음
- 자동 주문: 없음
- 현재 유료 투자자문/종목 추천 구독: 없음

## 공식 문의 질문

기능별로 각각 허용 여부와 필요한 제한 조건을 확인한다.

1. 시세·과거 수익률 단순 조회는 허용되는가?
2. 사용자가 직접 고른 종목 비교는 허용되는가?
3. 재무지표의 중립적 비교는 허용되는가?
4. 기술 조건 기반 종목 목록과 신호 점수는 허용되는가?
5. 투자 행동을 권하지 않는 규칙 기반 시장 설명은 허용되는가?
6. 관심종목 기준 외부 뉴스 선별 노출은 허용되는가?
7. 제한이 필요한 기능이 있다면 기능 제거 외에 소개 문구·딥링크·홈 노출에도 동일하게 적용해야 하는 조건은 무엇인가?

## 출시 판단

공식 답변이 오기 전에는 이 문서를 ‘승인 완료’로 표시하지 않는다. 허용되지 않은 기능을 이름만 변경하거나 심사 중 숨겨 통과시키지 않는다.
