# 차트뷰 출시 준비: 기능·성능 (2026-09-21)

목표: 원본 차트뷰의 조회 기능을 토스 내부에서 제공하고 불필요한 요청·화면 지연을 제거한다. 사용자는 0.8.1 휴대폰 검증 완료를 알렸으나 새 기능의 실기기 검증은 별개다.

## 설계

- 화면은 AIT에 번들링한다. 데이터 수집은 기존 GitHub Actions, HTTPS API는 기존 Render를 유지한다. 토스 SDK는 일반 데이터 수집 백엔드를 대신하지 않는다.
- `requestClient.js`: GET 요청 병합, 데이터별 짧은 TTL, 제한된 메모리 캐시, 총 요청 시간 제한, 호출자 취소와 네트워크 실패 구분. 오래된 캐시를 최신처럼 표시하지 않는다.
- `main.js`: 홈·상세의 응답을 독립적으로 표시. 화면 교체 후 기존 응답이 DOM에 접근하지 않게 한다. 차트 ResizeObserver 해제.
- `analysisData.js`/`analysisViews.js`: 기존 전체 스크리너의 검색·필터·정렬·페이지, 시장 히트맵, 사용자 선택 종목의 컨센서스·역사적 밸류에이션 데이터. 기준시각·결측값 표시.
- 원본 AI PICK/종목 추천/투자전략은 **이식 보류**. 현재 토스 서비스 오픈 정책 3-5/3-6과 충돌한다. 차트·증권정보 조회의 허용 범위도 공식 문의로 확인해야 한다. 문구 변경으로 우회하지 않는다.
- 원본 ID 기반 동기화는 인증 방식이 토스 정책과 맞지 않아 제외. SDK Storage를 유지한다.

## 실행·검증

1. 실제 API 시간·용량 측정 및 요청 경로 기록.
2. 요청 병합·만료·취소·실패·결측값에 실패하는 테스트를 작성하고 구현한다.
3. 홈/상세 독립 로딩과 화면 전환 회귀를 브라우저에서 검증한다.
4. 조회 기능의 필터/정렬/기준 표시 테스트, 320/390/430px 화면 확인.
5. 단위/모바일/실제 API/빌드 검사, PR 및 테스트 번들 등록.
6. 공식 정책 답변과 데이터 사용 권한·운영자 확인 없이 출시 가능 확인에 동의하지 않는다. 유료 인프라는 가격·효과를 제시한 뒤 승인된 경우에만 변경한다.
