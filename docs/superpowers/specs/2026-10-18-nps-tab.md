# 국민연금 국내주식 비중 탭

project_id: github:shoon94parkk-del/chart-view-toss
base_sha: ee65113 (2026-10-18 clone)
classification: new behavior

사용자 요청: 기존 차트뷰 토스에 국민연금 추정 기능을 통합한다. 토스의 작은 행·모바일 UI를 유지하고 메인은 요약, 자세한 근거는 명시적 펼침 뒤 보여준다. 시장 변화에 따라 데이터가 갱신되어야 한다.

분석 > 근거와 시장 환경 확인에 국민연금 입구를 추가하고 #pension, /pension 직접 진입을 제공한다. 기존 하단 네 개 탭과 native back을 사용한다. 첫 화면은 추정 국내주식 비중, 목표 차이, 총자산 유지 조건의 내부 조정액과 가격 기준일이다. 자산별 손익, 13F 검색 목록, 전제·출처, 선택 시나리오는 닫힌 상세로 제공한다. 13F 대용량 내역은 펼친 뒤 가져온다. 홈 첫 화면에는 NPS 요청·자산을 추가하지 않는다.

공유 서버 저장소에 별도 종가 수집 workflow와 public static/data/nps 게시물을 추가한다. 기존 API/수집기/웹 UI는 변경하지 않는다. 공통 완료 거래일의 관측 주가·환율과 명시적 채권·대체투자 근사로 분모도 재평가한다. 13F 수량 기준일과 시장 가격일은 분리한다. 미확인 기업행동·새 보고·누락은 현재값을 지어내지 않고 명시하며 검증 실패 시 이전 유효 게시물을 유지한다. summary와 versioned holdings는 동일 snapshotVersion을 확인한다.

앱은 요약을 재조회하고 열린 화면에서 5분마다 게시 확인한다. 이는 종가 게시 확인이며 실시간 보유액이 아니다. 재조회 실패 시 이전 결과와 실패 상태를 함께 유지한다. 이탈 시 timer/listener를 해제하고 늦은 응답을 무시한다. 출처는 기존 native openExternal을 사용한다.

검증은 순수 산식/게시물 검증 Node 테스트, API→가공→표시 E2E, 상세 지연로딩·실패/재시도·새 버전·뒤로가기 및 모바일 44px/넘침/axe를 포함한다. 기존 qa:prepush와 관련 mobile QA를 실행한다. 실제 Toss Android/iOS Sandbox는 웹 QA로 대체하지 않는다.
