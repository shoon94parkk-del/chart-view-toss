# Moneytoring 조사 후 토스 개선 범위

사용자가 [비교 조사](../../MONEYTORING_RESEARCH_2026-10-16.md)의 적용 가능한 항목 전체 구현과 가능한 경제지표 API 발급을 요청했다. 기존 기능을 확장하는 다섯 작업으로 나누어 실행한다. PICK/LAB의 선정·산식·점수·기록·성과·API/노출·면책은 보호한다. Native Sandbox와 API 계약은 실제 확인 여부를 구분한다.

## 1. 물가 예상치와 발표 읽기

기존6종 물가·두 변화율·1/3/5년 그래프를 유지한다. 자체 사전 캡처와 신뢰 가능한 공급자 보관 예상치의 사후 조회를 구분한다. `evidenceKind` 기본은 기존 `pre_release_capture`; 추가 `provider_archive`는 실제 조회시각/보관 근거/공급자/이벤트·기간·SA/NSA·단위가 확인되어야 한다. 시간을 소급 생성하지 않는다. 최초 실제와의 수치 비교를 확인할 수 없어도 출처가 검증된 예상치 표시와 비교 신호 가능 여부를 분리한다. 개별 예상치는 선택적 `row.forecasts`로 전달할 수 있으며 기존 `comparisons` 계약과 호환한다.

과거 발표 읽기는 기존6행의 확인된 발표/관측월로 최근3개 발표군부터 구성한다. 선택한 발표의 시리즈·기준월·공표·현재 지수 계산값/최초 발표값을 구분해 기존 읽기 화면에 연결한다. 예정/결과 대기/자료 있음/지연을 구분하고 CPI/PPI/PCE 의미 한 줄을 더한다. 현재 지수로 과거 최초 발표값이나 예상치를 만들지 않는다.

백엔드는 기존 정기 수집/저장 JSON을 확장하는 선택적 예상치 캐시만 읽는다. 앱 요청에서 공급자를 호출하지 않는다. 승인된 공급자와 데이터 계약이 없으면 수치 미제공/연동 대기다. 공식 문서로 확인한 API만 지원하고 키 발급·설정은 실제 수행 여부를 보고한다. 무료 가입도 사용자 이메일/인증 없이는 완료로 처리하지 않으며 새 유료 계약/결제/외부 연락은 하지 않는다.

## 2. 토스 뉴스 읽기

기존 종목 필터와 주요/최신 정렬을 유지하고 출처·직접/업종 관계 필터, 결과 범위/개수, 초기화·필터 빈 상태를 더한다. `items`뿐 아니라 이미 반환되는 종목별 `groups`를 사용해 같은 기사 URL의 모든 종목 연결과 각 관계 근거를 보존한다. 유사 제목만으로 같은 사건이라고 단정하지 않는다. 현재 선택 종목에 대한 관계로 필터한다.

카드는 제목/원문과 별도 `요약 보기`를 제공한다. 누를 때만 기존 `/api/news-summary`를 호출하고 원문/근거/품질·빈 상태/오류/재시도를 보인다. 같은 카드 중복 요청 방지, 최대3개 동시 요청, 화면 이탈 후 늦은 응답 방어를 둔다. 필터/정렬·요약 상태는 같은 방문의 상세 왕복에서 보존한다. 새 LLM·자동 일괄 요약은 없다. 홈의 시작 요청 수는 늘리지 않는다.

## 3. 차트 근거 날짜

기존 상세 수익률 영역 차트와 가격 계산을 유지한다. 이미 조회한 종목 뉴스에서 게시일과 원문이 확인된 이벤트를 선택형 마커/접근 가능한 날짜 목록으로 연결한다. 차트 관측일에 해당하는 게시일만 마커를 놓고 휴일/범위 밖 자료를 다른 날짜로 옮기지 않는다. KST 표시와 원래 시장의 날짜를 구분하며 날짜만 있는 자료는 날짜 정밀도를 유지한다. 같은 날짜는 묶는다. 수익률/가격 변동의 원인이라고 표시하지 않는다. 미국 뉴스4일 수집 한계를 밝힌다. 공식 공시 게시일이 확인되지 않은 재무기간에는 공시 마커를 만들지 않는다.

## 4. 연구 체크포인트

현재 기기/토스 계정별 연구 저장 키와 최신 메모를 유지한다. 명시적 메모 저장 때 최신 노트와 같은 쓰기에서 최근20개 체크포인트를 보존한다. 질문·비교종목·저장시각, 이미 확보된 canonical 시세의 가격/통화/관측시각/출처/기준만 담는다. 저장시각을 시세 시각으로 대신하지 않고 시세 부재는 부재로 둔다. 과거 기록을 현재 가격으로 복원하거나 수익률/투자 등급을 계산하지 않는다. 저장 실패·중복 클릭·삭제/계정 분리를 검증한다. 기존 `reviewOn`의 로컬 재확인 날짜 편집을 보완한다.

## 통합과 검증

`src/main.js`와 `src/api.js` 통합은 조정자만 수정한다. 뉴스/물가/차트 모듈은 실제 화면 진입 시 지연 로드하며 루트 로딩을 막지 않는다. 모듈별 소유 파일 외 편집/동시 브라우저 QA를 금지한다. 소규모 단위→기존 전체 Node/Python→API가공UI 브라우저→전체 prepush/모바일/접근성→AIT→PR CI 순으로 검증한다. 같은 조건으로95d6b83과 성능/요청 수를 비교한다. 기존 배포 권한·정상 main 승격 절차로 정확한 테스트 커밋을 게시하고 실제 화면과 자산을 확인한다.
