# 국민연금 공시 평가기준 추정 개선

사용자는 기존 국민연금 화면이 실제 기금 비중을 더 가깝게 따르도록, 확인된 계산 가정의 개선과 배포를 요청했다. 기존 요약 중심 Toss UI, 가격 갱신·실패 보존·13F 상세 지연조회 계약을 유지한다.

공식 자료로 확인한 국내 종합채권 ETF와 KRW·USD 단기금리 지표를 이용한다. 공식 단기자금·비금융·금융 조정잔액을 구분하고, 보험료·국고보조금에서 지출을 뺀 과거 외부 순유입 속도를 날짜에 맞춰 외삽한다. 운용수익은 외부 순유입에 다시 포함하지 않는다. 헤지 금리차 비용은 단기지표의 상대수익을 이용한 근사이며 실제 체결비용으로 표시하지 않는다.

사모 NAV의 발표 시차는 확인됐으나 모든 자산에 적용할 정확한 일수는 공개되지 않았다. 메인은 마지막 공시 NAV의 현지 가치 변동을 미확인으로 유지하고 환율을 갱신한다. 부동산·인프라·사모 등의 실제 공개 비중을 이용한 시장지표 재평가는 별도 사용자 시나리오다. 미확인 NAV 변동·분배금을 실제 0이라고 표시하지 않는다. 국내주식 실제 매매와 실제 헤지 집행은 미확인 가정으로 남긴다.

공개 schemaVersion1과 기존 다섯 그룹은 유지해 기존 화면과 호환한다. assetModel2는 현금 그룹 수익을 단기자금 수익·헤지 금리차 근사·순유입 이자로 계산한다. realism 및 cashBreakdown 메타데이터와 가정별 민감도 사례를 추가한다. 같은 결과를 Python·JS·독립 금액 계산으로 검증한다. 새 월별 공시는 감지하되 기준자료 변경은 검증 후 반영한다.

메인은 비중·목표차이·조정액·가격일만 유지한다. 세부 분류·NAV 한계·공시 날짜·가정별 결과는 접어서 제공한다. 시장 시나리오를 바꿔도 게시된 메인은 유지한다. 민감도 범위를 통계적 신뢰구간으로 표시하지 않는다.
