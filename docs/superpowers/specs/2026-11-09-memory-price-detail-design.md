# 반도체 가격 상세

분류: new behavior. 사용자는 토스 차트뷰의 반도체 가격 그래프, 누적 가격 이력과 품목별 세부 정보를 개선하도록 요청했다.

기존 Vite/vanilla JS, 독립 memory route와 공개 API를 유지한다. 현재 화면은 가족별 탭과 작은 SVG 품목 카드이며 날짜별 값을 탐색할 수 없다. 모바일의 작은 목록과 펼침 패턴을 지키면서 선택 품목 상세를 추가한다.

검토한 방식: 모든 품목 카드를 크게 만들면 긴 화면과 반복 조작이 생긴다. 별도 상세 route는 현재 가족별 Back/share 계약을 늘린다. 한 가족 안에서 품목 선택과 하나의 상세 영역을 제공하는 방식을 구현 판단으로 선택한다.

- 상세 영역: 품목 선택, 공개 평균가/등락/세션 고저가, 1개월·3개월·전체 수집 기간, USD 가격/시작값100 지수, 축과 눈금이 있는 큰 SVG.
- 날짜 탐색: 차트 터치/포인터와 키보드 range로 실제 관측일을 선택. 해당 가격, 직전 관측 대비, 기간 첫 관측 대비를 표시한다.
- 누적: 기간 첫값·마지막값·관측 평균·최고/최저·관측 수·실제 시작/종료일. 날짜별 가격과 직전 관측 대비 변화를 최신순 펼침 표로 제공한다. 누적은 수집된 가격 이력을 뜻하며 가격 합계를 만들지 않는다.
- 출처: 가족/품목 기준일과 공개 원문, 실제 공급 필드만 표시. 결측·실제0·단일 관측·불규칙 간격·과거 값·기준일이 다른 가족을 구분한다. HBM/MCP 가격 추정이나 과거 자료 생성은 하지 않는다.
- 선택 조작은 추가 API 요청을 만들지 않는다. 기존 TTL, retry, lifecycle, 탭 접근성, Toss navigation은 유지한다.

검증: 계산 Node 테스트 및 실제 API→가공→표시 E2E; 4기기, keyboard/touch, 320px overflow/44px 조작, axe, 기존 qa:prepush 및 관련 mobile QA. 실제 Android/iOS Toss Sandbox는 별도다.
