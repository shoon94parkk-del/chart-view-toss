# 국민연금 탭 Implementation Plan

> **For agentic workers:** Use executing-plans for root integration; the repository's chartview-agent-review workflow assigns a bounded independent data-pipeline owner and read-only final review.

**Goal:** 국민연금 요약과 눌러 보는 근거, 시장 종가 자동 갱신을 기존 토스 앱에 추가한다.
**Architecture:** 공유 데이터 저장소의 검증된 작은 summary + 동일 버전 상세를 기존 static CDN/API 경로로 읽는다. 화면은 독립 lazy module이며 기존 앱 셸·native 이동을 재사용한다.
**Tech Stack:** Existing Vite/vanilla JS, Node tests, pinned Playwright/axe; Python collector and GitHub Actions.
**Spec:** ../specs/2026-10-18-nps-tab.md

## Global Constraints
- 기존 네 개 하단 탭, 시세 최신성·홈 로딩·개인 저장·PICK/LAB를 유지한다.
- 원화 환율은 한 번만, 13F는 해외주식 잔액 안에서 적용한다.
- 실제 완료 가격일·보고일·추정 전제와 실패를 표시한다.

## Review Focus
- 오래된 응답이 새로운 게시물을 덮어쓰는 경우
- summary와 상세의 버전이 달라지는 경우
- 실제 0과 누락/비정상 값을 혼동하는 경우
- 상세를 열기 전 대용량 다운로드나 추가 홈 요청이 발생하는 경우
- 모바일 펼침·검색·native back이 고정 메뉴에 가리는 경우

## Tasks
1. Pure contract/model: tests/npsAllocation.test.mjs → src/npsAllocationModel.js. Failing tests first for total/weight/gap/adjustment, FX once, split scope, invalid/missing, old publication and version mismatch; implement and run Node suite.
2. Lazy UI: src/npsAllocationView.js + .css + npsAllocationData.js; routes/main/uiIdentity/export routes에 입구 연결. Summary request only, partial error retain/retry, versioned details on open, timers cleanup; four-browser API→UI and geometry tests.
3. Data publication: independent backend owner creates isolated scripts/nps + workflow + static files and tests. Use exact verified seed; no unverified new baseline. Check actual network + quality gates and preserve previous publication on failure.
4. Run npm run qa:prepush and existing mobile QA; read-only review actual diff; record decision/evidence. Push feature PRs, verify exact-SHA CI, integrate through existing main→Render promotion. Verify live assets and data separately; retain real-device limits.
