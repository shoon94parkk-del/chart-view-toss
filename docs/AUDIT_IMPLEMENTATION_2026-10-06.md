# 2026-10-06 점검 계획 구현 — 0.15.1

사용자 승인: 실제 사용 점검 계획에 따라 개선하고, 이미 해결한 문제를 반복하지 않도록 보호한다.

## 기존 계약과 분류

먼저 최신 main, CODEX_HANDOFF, no-repeat-regression-policy와 기존 결정·회귀 검사를 확인했다. 로컬 0.10.3을 0.15.0까지 fast-forward한 뒤 수정했다. 별도 Web UI는 수정하지 않는다.

## 회귀 검사

- `tests/auditExperience.test.mjs`: 날짜 복구, 검증된 뉴스 주소·미지원 주소, 개인 정보 없는 히트맵 공유, 최신 시세 라벨, IDEA 식별자.
- `tests/audit_plan_qa.mjs`: 320/390/1440px에서 실제 클릭·입력·상세 왕복. 홈 미국→지도 미국, 업종 종목, 날짜 오류→정상 적용, 공시 내부 이동, 필터 복귀, IDEA 펼침 복구, 종료 집계, HTTPS 기사 열기와 거절 안내.
- 새 브라우저 검사를 기존 `mobile-release-qa` CI와 main push 자동 검사에 추가했다. 기존 검사는 새 펼침 경로로 접근하도록 수정했으며 값·복귀·원자료 검증을 제거하지 않았다.
- 백엔드 `tests/test_audit_date_and_quote_basis.py`: 국내/미국 시간대, 범위 외 관측 제외 후 조정종가 수익률, 같은 날, 주말, 15:30/늦은 시각/시간 미제공 구분. 기존 비교 캐시/SWR/정규장·시간외 구분도 유지.

초기 재현 검사 6개는 기존 코드에서 실패했다. 원인 수정 후 백엔드 전체 459개, 프런트 단위 260개를 통과했다. 빌드·기존 모바일·실제 배포 화면의 최종 검증은 아래 산출물과 실행 결과를 기준으로 판정한다.

## 측정과 배포 검증

동일 390×844px Chromium 하네스로 변경 전/후 홈·삼성전자·엔비디아·KOSPI·밸류에이션 밴드·전체 히트맵을 측정한다. 현재 업종 지도 선택자로 하네스를 갱신해 양쪽에 동일하게 사용한다. 단일 실행은 SLA 또는 성능 향상 보장이 아니다.

로컬 증거: `output/audit-timing-before.json`, `output/audit-timing-after.json`, `output/playwright/audit-plan/results.json`, 배포 후 실제 동작 산출물. Render 서비스 상태, 백엔드 `/health`의 정확한 revision, 프런트 실제 asset/버전과 화면 조작을 함께 확인한다.

네이티브 Android/iOS 출시 검증은 웹 배포 검증과 별개다. 별도 서비스·유료 API·두 번째 시세 캐시를 추가하지 않았다.

배포 직전 Render 브랜치에만 있던 `c65513c`의 사용자 확정 EXIT 우선순위 수정을 main에 보존했다. 종료 기록은 기술 경고로 다시 진행 중이 되지 않으며, 새 회귀 검사가 모든 기술 경고와 조합해 확인한다.

## 최종 사용 검증과 보호 장치

- 실제 공개 사이트에서 320/1440px 홈 미국→전체 미국→업종 목록→NVDA 상세→복귀, 날짜 오류 복구, 공시 내부 이동, IDEA 펼침 복귀, PICK 집계를 조작해 통과했다. 화면 오류·가로 넘침 없음.
- 320/390px 실제 DART 삼성전자↔하이닉스 매출/영업이익 증가율, 영업현금흐름, 원자료·실적의 질·가격 지표 비교를 통과했다. 회사 선택을 명시하고 펼친 도움말/실적의 질에 접근하는 실제 경로로 live 검사도 갱신했다.
- main push 자동 검사에 새 320/390/1440px 사용 검사를 추가했다. Render 동기화는 배포 브랜치에만 남은 수정을 발견하면 실패하며, 통합 후 일반 push로만 진행한다. 별도 git 저장소를 만드는 검사로 미통합 수정 차단·통합 후 허용을 검증한다.
- 시세 검증기는 현재 원자적 스냅샷 출처명을 명시적으로 허용하며 미승인 출처·잘못된 값·시각은 계속 거절한다.
