## Usage rule

과장된 수익 약속이나 종목 추천 표현은 사용하지 않습니다. 차트뷰의 차별점은 실제 공시와 데이터 확인 흐름, 비교·스크리닝 편의성에 둡니다.


## Channel playbook

### 네이버 블로그
개발자 스토리 중심으로 소개합니다. 제목 예시: **주식 앱 보다가 공시까지 다시 찾는 게 귀찮아서 직접 만들었습니다**. 본문에는 DART 공시 확인 흐름, 종목 비교, 히트맵, 스크리너를 실제 사용 순서대로 보여주고 서비스 본주소 `https://chart-view-toss.onrender.com`을 사용합니다.

### 국내 투자 커뮤니티
광고 문구보다 피드백 요청형으로 작성합니다. 예시: **제가 주식 볼 때 쓰려고 만든 무료 분석 도구인데 한번 써보고 불편한 점 알려주실 분 계실까요?** 기능 나열은 짧게 하고 DART 공시까지 한 흐름에서 확인할 수 있다는 점을 먼저 설명합니다.

### GeekNews / Disquiet
메이커 관점의 문제-해결 구조로 소개합니다. **여러 앱을 오가며 차트와 공시를 따로 보던 불편을 줄이기 위해 만들었다**는 배경, 구현한 핵심 기능, 현재 개선 중인 부분과 피드백 받고 싶은 항목을 포함합니다.

### 이미지 운영 원칙
실제 종목의 현재가·등락률처럼 빠르게 변하는 값은 홍보 이미지에 고정하지 않습니다. 예시 차트는 `종목 A/B/C` 또는 명확한 샘플 표기로 사용하고, DART 공시·차트·히트맵·스크리너 등 제품 기능을 중심으로 홍보합니다.
