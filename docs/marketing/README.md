- DART 공시 기반 기업 정보 확인

### Instagram caption

주식 앱에서 숫자를 보다 보면 결국 공시까지 다시 찾아보게 되더라고요.

그래서 그 흐름을 한곳에 모았습니다.

한국·미국 주식 비교, 히트맵, 스크리너, 밸류에이션, 관심종목 수익률 비교까지 한곳에서 볼 수 있게 만들었습니다.

프로필 링크에서 무료로 써보세요.
직접 써보시고 이상한 데이터나 불편한 점이 있으면 알려주세요.
