# 전체 기능·사용성 재점검 · 2026-10-02

## 확인한 문제와 개선

| 확인한 문제 | 개선 후 동작 |
| --- | --- |
| 차트 API가 HTTP 200으로 빈 자료를 반환하면 ‘다시 시도’가 60초 캐시를 다시 읽었다. | 최초 오류, 기간 변경 오류, 종목 상세 차트의 명시적 재시도는 클라이언트 캐시를 건너뛴다. 정상 기간 조회의 캐시는 유지한다. |
| 비교 종목 일부만 조회돼도 누락 정보가 접힌 계산 기준 안에 있었다. | 차트 바로 위에 선택/표시 개수와 누락된 종목명을 표시하고 재시도를 제공한다. 조회된 차트는 유지하며 누락 종목을 0%로 만들지 않는다. |
| 미국 종목에 없는 ‘산업’ 바로가기와 제출 뒤에야 거절하는 DART 질문창이 있었다. | 국내 종목에만 산업·DART 공시 비교를 제공한다. 국내 회사의 산업 자료가 없을 때도 대응 바로가기를 제거한다. 남은 메뉴는 같은 너비를 사용한다. |
| 관련 뉴스 조회 실패를 ‘관련 뉴스 없음’으로 표시했다. | 실패와 정상 빈 결과를 구분한다. 뉴스만 다시 요청하는 버튼과 로딩 표시를 제공한다. 종목명 조회 실패도 티커 기준 뉴스 요청을 막지 않는다. |
| 웹에서 원문이 실제로 열려도 외부 링크 실패 안내가 표시됐다. | `noopener`의 null 반환을 오류로 판단하지 않는다. HTTPS 검사와 새 창의 opener 격리는 유지하며 실제 호출 예외 및 네이티브 실패는 실패로 처리한다. |

외부 링크의 null 반환 원인은 [MDN Window.open 문서](https://developer.mozilla.org/en-US/docs/Web/API/Window/open#noopener)와 별도 Chromium 회귀 재현으로 확인했다. 브라우저 팝업 차단 여부는 `noopener` 반환값으로 판별할 수 없으므로 호출 성공을 원문 사이트 로딩 성공으로 단정하지 않는다.

## 점검 범위

- 운영 모바일 390px 및 데스크톱 1440px: 검색 → 종목 상세 → 관심등록 → 관심목록 재방문, 관심종목 우선 선택, 선택창 취소/Escape/초점 복귀, 국내·미국 섹터 → 구성 종목 상세, 지수 진입, 기업 지표 탭, 종목별 뉴스.
- 오류 주입 회귀: 320/390/430px에서 빈 200 응답 → 복구, 부분 비교 → 복구, 실패한 기간 변경 → 기존 차트 보존 → 복구, 상세 차트 복구, 뉴스 503 → 뉴스만 복구, 국내 산업 자료 누락 메뉴, 미국 DART 메뉴 제외.
- 외부 원문: 실제 새 탭 생성, `window.opener === null`, 잘못된 실패 안내 없음. 외부 기사 자체의 내용/접속 가능성을 시험하기 위한 검사가 아니다.
- `tests/reliability_audit_qa.mjs`에 위 사례를 보존한다. 운영 사이트의 오류 복구 검사는 운영 자산을 사용하고 API 응답만 격리된 브라우저에서 주입한다. 자연 발생한 실제 서버 장애와 구분한다.
