## 검증과 범위

175개 단위 검사·AIT 계약, 19개 정적 진입 경로 및 빌드 통과. 새 `redesign_review_qa.mjs`는 320/390/430px에서 관심 별칭(해시와 직접 경로), 실제 0/미제공 점수·출처·펼침·넘침, 실제 canvas에 그려진 십자선 날짜를 검사한다. 기존 `value_discovery_qa.mjs`의 네 폭, exact 기록·첫 결과·수동 조건·뒤로 복원·수출 이동도 통과했다. CI에 새 QA와 캡처 업로드를 추가했다.

원본 리뷰의 관측 당시 자료 버전·네트워크 응답·브라우저 캐시 증거가 없으므로 과거 PICK 변경 원인을 복구해 확인했다고 주장하지 않는다. 현재 세 API 표본의 해시는 `faec23f88bee35152ba4026b768b6b53091db6459cf3279e317620af17799ece`였다. 재검증 원자료는 작업 산출물 `redesign-picks-probe.json`, `redesign-financial-evidence.json`, `redesign-live-evidence.json`에 보관한다.

가격/PER 비교는 해당 시각의 API 표시값 검증이지 미래 수익성 예측이 아니다. Yahoo의 [삼성전자 통계](https://finance.yahoo.com/quote/005930.KS/)도 자료 기준일별 forward/trailing 값을 구분한다. 라이브러리 날짜 설정은 [공식 LocalizationOptions](https://tradingview.github.io/lightweight-charts/docs/4.1/api/interfaces/LocalizationOptions)와 설치된 타입을 확인했다.

캐시·시세 병합·백엔드 수집·추천 날짜/가격·매매 상태·지표 산식·네이티브 저장/뒤로가기는 이번 변경 범위에 없다. Render 웹 완료와 토스 실기기·공개 출시 게이트는 구분한다.
