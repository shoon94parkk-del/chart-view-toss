- 첫 순차 수집이 20분 제한에 가까워져 이후 수집에는 승인된 동시성 2를 사용. 요청 예산·020 전역 중단을 lock으로 검증했고 thread별 HTTP 세션을 사용함. 비용은 제한 응답 전에 이미 시작된 최대 2개 요청이 마무리될 수 있다는 점과 같은 총량 내 순간 요청 증가임.
- 기간 조회를 공식 다중회사 API로 묶고 사용하지 않는 결산월 프로필 조회 제거. 동일 회사·접수번호·재무 기준이 일치하지 않으면 개별 API로 재확인한다. 비용은 첫 기업 전에 묶음 요청과 수집기 메모리의 기간 캐시가 추가된다는 점이며, 동일 요청/시간 상한과 금융 검증을 유지한다.
- 실수집에서 묶음 선조회가 이전보다 느려졌으므로 제거하고 개별 기간 검증으로 복귀. 비용은 기업별 기간 API 요청 증가이고, 이전 실행에서 실제 확인한 처리 방식으로 되돌렸다. 공급자 내부 지연 원인을 단정하지 않는다. 불필요한 결산월 요청 제거는 유지한다.
- 독립 리뷰는 운영 통합 이전에 수행. 실제 수집·배포 결과는 이후 별도 검증해 공개 전 코드 문제를 먼저 해결함. 비용은 실데이터에서 발견한 문제를 추가 회귀로 검증해야 한다는 점.

리뷰의 Critical 및 보류한 Minor는 없음. 실제 DART 정확도/배포/최종 레이아웃은 이 기록의 후속 검증으로 판단하며, Android/iOS Toss Sandbox는 실기기 증거가 없으므로 **미검증**이다. Render 미리보기 배포와 Toss 공개 출시를 구분한다.
