# 시장 먼저 확인하는 홈과 선정 기록 동선 · 0.12.0

사용자의 새 요청으로 기존 발견성 중심 배치를 조정하는 새 동작이다. 0.11.2 운영 홈을 390×844에서 직접 사용했을 때 관심 제목은 1,249px, 주요 시장 제목은 1,397px 아래였다. 긴 선정 이유와 중복 진입이 매일 확인할 시장/내 종목을 밀고 있었다. 이 기록은 첫 방문의 화면 위치 측정이며 이용자 설문 결과가 아니다.

| 사용 목적 | 새 배치/동작 | 확인 기준 |
|---|---|---|
| 지금 시장은 어떤가 | 검색 다음에 주요 시장 4개와 실제 기준시각 | 320×693 첫 화면에서 카드 전체 확인. 추가 지표·실패 재시도 유지 |
| 차트뷰만의 데이터에 접근 | 시장 바로 아래 수출·조건 검색·선정 기록 3진입 | 세 진입도 첫 화면에서 표시. 전체 스크리너/히트맵/수출 상세를 미리 받지 않음 |
| 내 종목 확인 | 긴 발견성 피드보다 앞에 관심 배치 | 390×844 미등록/1종목 등록 상태 전체 확인. 기존 저장·정렬·시세 수렴 유지 |
| 선정 이후 결과 확인 | 전체 평가 기록 평균·플러스 비율·평가 분모를 펼침 없이 노출 | 미평가 제외·서로 다른 선정일/기간·산술 평균·매매비용 및 포트폴리오 차이를 설명 |
| 특정 선정 종목의 근거 확인 | 최근 이름·선정일·상태 행 전체를 클릭 | 해당 날짜/코드의 PICK만 열고 원문 이유/기업 상세를 기록에서 확인 |
| 기능 구분 | ‘전체’를 ‘분석’으로 표시, 종목 찾기/선정 기록/비교/시장 근거로 구분 | 목적 이동은 같은 화면 안에서 수행. 주소/뒤로가기 이력 불변. 네 탭의 용도 안내 |

홈에는 결과 요약과 최근 선정 이름을 함께 보여준다. 이름만 강조하면 실시간 인기 순위처럼 읽히고, 평균만 강조하면 무슨 종목과 기간인지 감춰진다. ‘선정 기록·성과’라는 명칭, 평가 분모/계산 기준, 최근 기록 클릭을 함께 제공한다. 기존 숫자와 선정/현재 점검/기술 상태의 의미는 변경하지 않는다. 사용자 확인 시간을 실측하지 않았으므로 발견 시간 감소 수치나 투자 성과 개선을 주장하지 않는다.

홈 순서는 검색 → 주요 시장 → 핵심 분석 → 관심 → 선정 기록·성과 → 조건/수출 미리보기 → 대표 히트맵 → 시장 요약/빠른 비교/등록 종목 뉴스다. 홈 대표 6종목과 전체 종목/섹터 탐색 구분은 유지한다.

회귀 검사는 새 `home_journey_qa.mjs`의 320/390/430px × 미등록/등록/시장 오류 9개 상태, 이전 `value_discovery_qa.mjs`의 4개 폭 및 전체 mobile CI를 함께 사용한다. 기존 시장 전개/동일 시세/뒤로가기/관심 저장/선정 상태/기술 경고/출처/조건 복원 검사는 유지하고, 이전 시장 후행 순서와 변경한 표시명에 관한 기대만 새 승인 계약으로 바꾼다. 결과와 배포 증거는 작업 산출물 보고서에 보관한다.

Render 웹 개선 범위이며 AIT 실기기·공개 출시 게이트를 대신하지 않는다. 기존 Playwright/Render 도구를 사용하며 새 스킬이나 외부 투자 판단 기능은 추가하지 않는다.
