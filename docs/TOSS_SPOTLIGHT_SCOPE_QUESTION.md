# 토스 추가 확인용 화면 범위 초안

기존 문의의 답변은 무료 조회형 서비스 입점 가능, 종목 추천·투자 권유는 어려움이었다. 아래 기능은 그 답변에 포함됐다고 가정하지 않는다. 실제 선정 방식과 화면을 숨기지 않고 재확인한다.

## 확인할 기능

- 홈·전체 메뉴·기록 화면 제목: `최근 주목받는 종목`
- 대상: 기존 Chart View의 선정 로직이 산출한 한국·미국 주식 최대 3개. 운영자가 관심을 가진 기업을 보여주려는 의도이며, **기존 추천 선정 결과와 같은 종목**이다.
- 현재 `0.9.4` 미리보기: 홈에 선정 기업명·종목코드·선정일·1~3번 순위와 과거 추천의 평균 수익률·플러스 비율을 표시한다. 상세 기록 화면에는 추천일/추천가, 현재 점검가/수익률, 최고수익률, 점수·이유, 유지/경계/매도검토 등 사후점검 상태와 투자논리 근거를 표시한다. 원본 선정 결과와 성과 데이터는 변경하지 않았다.
- 외부 웹서비스 유도, 주문·중개·유료 자문은 없다.

## 문의 문안

> 앞서 `chartview`의 무료 조회형 미니앱은 입점 가능하고 종목 추천·투자 권유는 어렵다는 답변을 받았습니다. 현재 미리보기에는 기존 Chart View의 **사용자 확정 선정 결과와 같은 종목**을 `최근 주목받는 종목`이라는 제목으로 복원했습니다. 홈에는 최대 3종목의 순위·선정일과 기존 추천 평균 수익률·플러스 비율을 보여줍니다. 연결된 기록 화면에는 추천가·점검가·수익률·점수·선정 이유와 투자논리 사후점검 상태도 나옵니다. 매매·중개·유료 자문·외부 웹서비스 유도는 없습니다. 제목을 바꿔도 이 실제 화면이 종목 추천·투자 권유에 해당해 입점이 어려운지, 허용 가능한 축소 범위가 있다면 어떤 데이터와 표현을 제외해야 하는지 확인 부탁드립니다. 화면 캡처와 선정 기준을 제공할 수 있습니다.

이 문안은 전송하지 않았다. 제목 변경만으로 현재 화면이 허용됐다고 표시하지 않으며, 추가 답변 전에 공개 Toss 심사를 제출하지 않는다.
