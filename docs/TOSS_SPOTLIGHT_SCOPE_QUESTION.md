# 토스 추가 확인용 화면 범위 초안

기존 문의의 답변은 무료 조회형 서비스 입점 가능, 종목 추천·투자 권유는 어려움이었다. 아래 기능은 그 답변에 포함됐다고 가정하지 않는다. 실제 선정 방식과 화면을 숨기지 않고 재확인한다.

## 확인할 기능

- 홈 제목: `오늘 주목받는 종목`
- 대상: 기존 Chart View의 선정 로직이 산출한 한국·미국 주식 최대 3개. 운영자가 관심을 가진 기업을 보여주려는 의도이며, **기존 추천 선정 결과와 같은 종목**이다.
- 토스 화면 후보: 기업명·종목코드·선정 기준일·출처 및 종목 상세의 과거 시세만 제공. 매수·매도 문구, 순위 배지, 점수, 예상 수익률, 추천 이유, 추천 성과, PICK 사후점검·투자논리 문구는 표시하지 않는다.
- 외부 웹서비스 유도, 주문·중개·유료 자문은 없다.

## 문의 문안

> 앞서 `chartview`의 무료 조회형 미니앱은 입점 가능하고 종목 추천·투자 권유는 어렵다는 답변을 받았습니다. 기존 Chart View의 선정 로직으로 뽑힌 3개 기업을 홈의 `오늘 주목받는 종목`에 기업명·코드·선정 기준일만 표시하려고 합니다. 원래 추천 선정 결과와 **같은 종목**이며, 명칭을 변경하더라도 실질적인 종목 추천으로 판단되는지 확인 부탁드립니다. 점수·순위·추천 이유·예상/과거 추천 성과·매수/매도 문구·PICK 관리 화면은 토스에서 제외할 계획입니다. 이런 구성도 제한된다면 홈에서 선정 기업 목록 자체를 제외하겠습니다. 실제 화면 캡처와 선정 기준 설명이 필요하면 제공하겠습니다.

이 문안은 전송하지 않았다. 토스가 해당 구성을 명시적으로 허용하기 전에는 Toss 빌드의 `TOSS_RECOMMENDATIONS_ALLOWED`를 켜지 않는다. 명칭 변경만으로 허용된다고 표시하지 않는다.
