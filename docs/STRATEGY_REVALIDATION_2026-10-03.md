## 3. 이번 구현

### 큰 변동의 해석 안내

일간 등락률의 절댓값이 35% 이상이면 스크리너 행과 LAB 후보에 “변동 기준 확인” 및 원자료 확인 문장을 표시합니다. 35%는 주의를 환기하는 제품 기준이며 거래소 공통 가격제한폭이나 오류 확정 기준이 아닙니다.

원래 종가·등락률·RSI·선정 순위를 보존합니다. 해당 종목을 숨기거나 데이터를 보정하지 않습니다. RSI 0만으로 오류를 만들지 않으며 null·빈 문자열·Infinity는 변동값으로 취급하지 않습니다. 영문 혼합 코드에도 이유 없는 경고를 붙이지 않습니다.

### 검색과 기술 조건의 교차 적용 설명

검색어·시장·기술 조건이 함께 적용된다는 안내를 표시합니다. 결과가 없으면 같은 검색어·시장에서 기술 조건 없이 찾을 수 있는 종목이 있는지 기존 `filterScreener`로 확인합니다.

- 검색어·시장에는 해당하지만 기술 조건에서 탈락한 경우: 제외 종목 수와 기술 조건 해제 버튼.
- 검색어·시장에 해당하는 종목 자체가 없는 경우: 종목명·코드·시장 확인 안내.
- 기술 조건 해제: 검색어·시장 유지, RSI/거래량/수익률/거래대금/추세/신호 해제, 정렬·페이지 초기화.

상단의 해제 버튼도 실제 입력값을 지웁니다. 수동으로 변경한 기술 조건에도 해제 버튼이 나타납니다. 상세 진입 후 뒤로 돌아오면 해제된 조건과 검색어·시장이 그대로 유지됩니다.

수정 분류는 **새 데이터 해석 안내 및 기존 프리셋 해제 동작의 새 버그**입니다. 기존 검색·시세·캐시 구조를 교체하지 않았고 공용 API 스키마·저장 키·네이티브 내비게이션은 유지했습니다.

## 4. 조정된 우선순위

1. **현재 운영 사실 확인**: 허용 호스트 적용 후 토스 사이트의 홈·상세·LAB·스크리너·PICK·관심·수출 화면과 화면에서 사용하는 데이터를 대조합니다. 토스 소스 버전과 운영 번들을 기록합니다.
2. **확인된 스크리너 해석·복구 문제**: 이번 코드 수정 및 회귀 검사. 운영 반영은 아직 완료하지 않았습니다.
3. **기존 투자 근거 기능의 발견성**: 관심종목에서 저장한 근거로 바로 이동하는 경로와 마지막 확인 상태를 먼저 설계·사용자 검증합니다. 충족·미충족·확인 불가·새 공시를 구분하고 공시 기반 범위를 유지합니다.
4. **방법론 투명성**: PICK 표본·기간·계산 방식 및 수출 데이터의 기간·분류 설명을 실제 응답과 대조합니다. 보고서의 성과 숫자를 슬로건에 고정하지 않습니다.
5. **수출→기업 탐색**: 우선 제품 근거가 있는 제한된 품목으로 탐색 흐름을 검증합니다. 기업 실적 기여나 매수 신호를 자동 생성하지 않습니다.

2주·1개월·분기라는 일정과 전환율·재방문율 향상은 검증된 약속이 아닙니다. 구현 범위, 데이터 갱신 주기, 실제 사용 관찰을 거쳐 정해야 합니다. Apps in Toss 공개 출시 판단에는 저장소의 기존 `P0_RELEASE_GATE.md`가 적용되며 웹 브라우저 검사를 네이티브 출시 완료로 취급하지 않습니다.
