## 검증 명령

- `npm run build`: 단위·계약 검사, 프로덕션 번들, 직접 진입 경로 검사
- `node tests/experience_audit_qa.mjs`: 320/390/430px 신규 탐색 흐름
- `node tests/research_card_qa.mjs`: 동일 기간 계산·실패 재시도·결측값·질문 저장
- `node tests/analysis_qa.mjs`: 스크리너·분석 도구·기간·결측값
- `node tests/loading_share_qa.mjs`: 로딩·이전 차트 유지·공유 조건
- `node tests/financial_flow_qa.mjs`: 실적·산업·전체 메뉴의 모바일 구성

브라우저 캡처는 `output/playwright/experience-audit`, `output/playwright/research-card`, `artifacts/analysis-qa`, `artifacts/financial-flow`에 생성된다. 실제 Android/iOS Toss 런타임 검증은 기존 출시 게이트를 따른다.
