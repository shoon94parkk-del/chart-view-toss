## 발견과 수정

1. **앱의 모바일 터치 기준 미달**: 짧은 산업 탭 폭40px, 반도체 그래프 선택기 높이40px를 실제 브라우저에서 확인했다. 기존 mobile stylesheet에 minimum44px만 추가했다. 모든 모바일 탭과 graph picker hit-test로 회귀를 보호한다.
2. **배포 경로의 QA 우회**: 기존 sync가 QA와 독립적으로 실행됐다. `needs: qa`로 모든 결정론적 핵심 검사를 기다린다.
3. **미검사 최신 커밋 promotion 가능성**: 기존 sync는 새로 fetch한 main을 push해 검사 커밋과 배포 커밋이 달라질 수 있었다. 정확한 `github.sha`와 최신 main 일치를 확인한 후 그 SHA만 push한다. 기존 ancestry 검사/no-force를 유지한다.

초기 잘못된 테스트 가정도 구분해 수정했다: KOSPI 실제 라벨, 정수/소수 수출액 표시, 독립 공시 retry 선택, 고정 하단 메뉴를 고려한 사용자 스크롤, optional 요청 종료 시 테스트 teardown, 비동기 스크롤 중 여러 프레임 좌표 혼합. 테스트 완화를 통한 앱 버그 은폐는 하지 않았다.
