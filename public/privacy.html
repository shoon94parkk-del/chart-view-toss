개인정보 처리 안내

시행일: 2026-09-21
요약

Chart View for Toss는 현재 별도 회원가입이나 자체 계정 기능을 제공하지 않으며, 관심종목과 비교종목은 이용자의 기기 저장소에 보관됩니다.

1. 서비스에서 다루는 정보

종목 검색어, 선택한 종목 코드, 관심종목 목록 등 서비스 이용에 필요한 입력값이 처리될 수 있습니다. 관심종목과 비교종목은 현재 브라우저·웹뷰의 로컬 저장소에 저장됩니다.

2. 서버 통신

시세·재무·경제지표·뉴스를 불러오기 위해 선택한 종목 코드와 검색어가 Chart View 백엔드로 전송될 수 있습니다. 호스팅·네트워크 사업자는 서비스 운영 과정에서 일반적인 접속 로그를 처리할 수 있습니다.

3. 제3자 데이터

서비스는 외부 시장·재무·뉴스 데이터 제공처의 정보를 조회하거나 연결합니다. 외부 뉴스 링크를 열면 해당 사이트의 개인정보 처리방침이 적용됩니다.

4. 보관과 삭제

기기에 저장된 관심종목·비교종목 정보는 서비스 데이터 삭제, 브라우저·앱 데이터 삭제 또는 저장소 초기화 시 제거될 수 있습니다.

5. 광고·판매

현재 Chart View for Toss는 이용자의 관심종목 데이터를 광고주에게 판매하지 않습니다.

6. 변경

로그인·클라우드 동기화 등 개인정보 처리 범위가 확대되는 기능을 추가할 경우 이 안내를 갱신합니다.
