개인정보 처리 안내

시행일: 2026-09-21
요약

Chart View for Toss는 현재 별도 회원가입이나 자체 계정 기능을 제공하지 않으며, 관심종목과 비교종목은 이용자의 기기 저장소에 보관됩니다. 토스의 익명 사용자 식별키로 기기 내 사용자별 목록을 구분합니다.

1. 서비스에서 다루는 정보

종목 검색어, 선택한 종목 코드, 관심종목 목록 등 서비스 이용에 필요한 입력값이 처리될 수 있습니다. 관심종목과 비교종목은 토스 앱의 기기 저장소(웹 미리보기에서는 브라우저 로컬 저장소)에 저장됩니다.

익명 식별 및 이용 기록

토스 SDK에서 발급받은 익명 식별키와 최초·최근 이용시각, 실행 횟수를 기기 저장소에 보관합니다. 이 값은 자체 서버나 분석 업체로 전송하지 않습니다. 현재 기기에서 계정별 목록 복원에 사용하며, 다른 기기로 자동 동기화하지 않습니다. 초기화는 현재 사용자의 목록·이용 기록을 삭제하며 계정 구분용 식별키는 유지됩니다. 앱 저장소 삭제 시 기기 내 모든 값이 제거됩니다.

2. 서버 통신

시세·재무·경제지표·뉴스를 불러오기 위해 선택한 종목 코드와 검색어가 Chart View 백엔드로 전송될 수 있습니다. 호스팅·네트워크 사업자는 서비스 운영 과정에서 일반적인 접속 로그를 처리할 수 있습니다.

3. 제3자 데이터

서비스는 외부 시장·재무·뉴스 데이터 제공처의 정보를 조회하거나 연결합니다. 외부 뉴스 링크를 열면 해당 사이트의 개인정보 처리방침이 적용됩니다.

4. 보관과 삭제

기기에 저장된 관심종목·비교종목 정보는 앱의 ‘데이터 및 이용 안내 → 기기 데이터 초기화’에서 직접 삭제할 수 있고, 브라우저·앱 데이터 삭제 또는 저장소 초기화 시에도 제거됩니다.

5. 광고·판매

현재 Chart View for Toss는 이용자의 관심종목 데이터를 광고주에게 판매하지 않습니다.

6. 변경

로그인·클라우드 동기화 등 개인정보 처리 범위가 확대되는 기능을 추가할 경우 이 안내를 갱신합니다.

7. 지원 및 삭제 문의

현재 별도 회원계정이 없어 서버에서 관심종목 목록을 삭제하는 기능은 없습니다. 기기 저장 정보는 앱·브라우저 데이터 삭제로 제거할 수 있습니다. 서비스 오류·데이터 처리 관련 문의는 kimtang89@naver.com에서 접수합니다.
