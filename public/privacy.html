요약

Chart View for Toss는 현재 별도 회원가입이나 자체 계정 기능을 제공하지 않으며, 관심종목, 비교종목과 조사 카드, 최근 본 종목 최대 5개와 관심 목록 정렬 설정은 이용자의 기기 저장소에 보관됩니다. 토스의 익명 사용자 식별키로 기기 내 사용자별 목록을 구분합니다. 접속 상태 확인을 위한 백엔드 통신과 토스 공식 SDK를 통한 이용 품질 측정이 있으며, 개인 조사 질문·메모는 측정 이벤트에 포함하지 않습니다.

1. 서비스에서 다루는 정보

종목 검색어, 선택한 종목 코드, 관심종목 목록 등 서비스 이용에 필요한 입력값이 처리될 수 있습니다. 관심종목, 비교종목과 조사 카드는 토스 앱의 기기 저장소(웹 미리보기에서는 브라우저 로컬 저장소)에 저장됩니다.

익명 식별 및 이용 기록

토스 SDK에서 발급받은 익명 식별키와 최초·최근 이용시각, 실행 횟수를 기기 저장소에 보관합니다. 기기 내 기록은 현재 기기에서 계정별 목록 복원에 사용하며 다른 기기로 자동 동기화하지 않습니다. 접속 상태 확인을 위해 이 익명 식별키를 바탕으로 한 방문 식별값과 현재 화면의 큰 분류가 Chart View 백엔드로 전송됩니다. 웹 미리보기에서는 브라우저에서 만든 무작위 방문 식별값을 사용합니다. 이 접속 통신은 중복 방문 집계와 시장 자료 갱신에 사용하며 화면 조회나 저장 성공을 측정하는 이벤트와 구분합니다. 서버는 방문 식별값을 날짜별 해시로 바꾸어 기록합니다. 메모리의 마지막 접속 상태는 24시간을 넘으면, 일별 방문값은 오늘부터 7일 전보다 오래된 날짜가 되면 이후 접속 처리에서 정리합니다. 별도 서버 저장소를 사용하는 경우 일별 방문값은 마지막 접속 처리부터 10일 후 만료하도록 설정됩니다. 초기화는 현재 사용자의 목록·조사 카드·이용 기록을 삭제하며 계정 구분용 식별키는 유지됩니다. 앱 저장소 삭제 시 기기 내 모든 값이 제거됩니다.

조사 카드의 질문, 확인한 내용, 반대 단서와 다시 볼 날짜는 현재 기기에만 저장하며 서버나 LLM으로 전송하지 않습니다. 다시 볼 날짜는 메모이며 자동 알림을 보내지 않습니다.

질문을 명시적으로 저장하면 종목별 최근 20개의 연구 체크포인트를 함께 보관합니다. 질문·확인 내용·반대 단서·다시 볼 날짜·저장 시각과, 이미 조회된 시세가 있는 경우 가격·통화·출처·관측 시각·자료 기준을 현재 기기에 저장합니다. 체크포인트 저장을 위해 과거 시세를 새로 조회하거나 수익률을 계산하지 않습니다. 이 기록은 서버·분석 이벤트·공유 링크로 보내지 않으며 해당 질문 삭제 또는 기기 데이터 초기화로 함께 삭제됩니다.

이용 품질 측정

지원되는 토스 앱에서 토스 공식 Analytics SDK로 실행, 화면 이용, 실제 검색 결과 표시, 종목·분석·수출 자료 표시, 관심종목·조사 질문 저장 성공과 실패, 복구 가능한 오류, 선택적인 후기 안내 표시·화면 요청 시도와 실패·안내 닫기를 측정합니다. SDK가 anonymous_key를 자동 포함하며 토스 분석 시스템으로 전송합니다. 앱이 추가하는 값은 정해진 화면·결과·오류 분류, 제한된 결과 수와 10밀리초 단위로 반올림한 로딩 시간입니다.

검색어, 종목 코드, 조사 질문과 메모는 이용 품질 측정 이벤트에 포함하지 않습니다. 관심종목 목록, 투자 금액, URL, 원본 오류 내용이나 별도 사용자 식별값도 추가하지 않습니다. 웹 미리보기에서는 이 SDK 측정 이벤트를 전송하지 않으며 토스 Sandbox에서는 SDK가 콘솔에만 기록합니다.

선택적인 이용 후기 안내

관심종목 또는 조사 질문을 실제로 저장한 뒤 지원되는 토스 앱에서 이용 후기 버튼을 안내할 수 있습니다. 후기 화면은 이용자가 버튼을 누를 때만 요청합니다. ‘지금은 건너뛰기’로 이번 방문의 안내를 닫거나 ‘다시 안내하지 않기’로 이후 안내를 끌 수 있습니다. 안내 시각과 안내 중지 설정은 기기에서 계정별로 저장하며 안내 사이에 최소 30일을 둡니다. 앱은 후기 작성 여부·별점·후기 내용을 확인하거나 측정하지 않습니다.

2. 서버 통신

시세·재무·경제지표·뉴스를 불러오기 위해 선택한 종목 코드와 검색어가 Chart View 백엔드로 전송될 수 있습니다. 호스팅·네트워크 사업자는 서비스 운영 과정에서 일반적인 접속 로그를 처리할 수 있습니다.

3. 제3자 데이터

서비스는 외부 시장·재무·뉴스 데이터 제공처의 정보를 조회하거나 연결합니다. 외부 뉴스 링크를 열면 해당 사이트의 개인정보 처리방침이 적용됩니다.

4. 보관과 삭제

최근 본 종목은 검색창의 ‘최근 본 기록 지우기’로 지울 수 있습니다. 기기에 저장된 관심종목·비교종목·조사 카드·후기 안내·최근 본 종목·정렬 설정은 앱의 ‘데이터 및 이용 안내 → 기기 데이터 초기화’에서 직접 삭제할 수 있고, 브라우저·앱 데이터 삭제 또는 저장소 초기화 시에도 제거됩니다. 기기 데이터 초기화는 이미 전송된 서버 접속 기록이나 토스 분석 기록의 삭제를 의미하지 않습니다. 서버 접속 기록과 토스 분석 기록의 보관·삭제 기준은 아래 연락처로 문의할 수 있습니다.

5. 광고·판매

현재 Chart View for Toss는 이용자의 관심종목 데이터를 광고주에게 판매하지 않습니다.

6. 변경

로그인·클라우드 동기화 등 개인정보 처리 범위가 확대되는 기능을 추가할 경우 이 안내를 갱신합니다.

7. 지원 및 삭제 문의

현재 별도 회원계정이 없어 서버에서 관심종목 목록을 삭제하는 기능은 없습니다. 기기 저장 정보는 앱·브라우저 데이터 삭제로 제거할 수 있습니다. 서비스 오류·데이터 처리 관련 문의는 kimtang89@naver.com에서 접수합니다.
